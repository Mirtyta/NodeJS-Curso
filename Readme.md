# 📘 Repositorio de Aprendizaje: Node.js 🚀

## ¡Hola, equipo! 👋

Bienvenidos a este espacio colaborativo. He creado este repositorio con el objetivo de centralizar todo el material que vamos trabajando en clase. La idea es que tengamos un punto de referencia ordenado donde consultar los **cuestionarios** (una vez revisados con el profesor) y los **ejercicios prácticos** que vayamos resolviendo.

Este repositorio es para nosotros: para reforzar lo aprendido, sacarnos dudas y tener el código a mano cuando lo necesitemos. ¡Espero que les sirva muchísimo en este camino de convertirnos en expertos de Node!

## Como empezar

Si quieres tener una copia local para practicar o consultar el código:

1. **Clonar el repositorio:**

   ```bash
   git clone https://github.com/Mirtyta/NodeJS-Curso.git
   ```

2. **Instalar dependencias:**

   ```bash
   npm install
   ```

3. **Ejecutar un archivo:**

   ```bash
   node nombre_carpeta/archivo.js
   ```
