Clase N° 7- Cómo funciona la web

¿Cómo funciona Internet?

Internet es una red global que conecta dispositivos de todo el mundo mediante un protocolo (lenguaje común). Cada nodo, ya sea una PC, móvil o servidor, tiene una dirección IP única para ser localizado. Hacemos todo este despliegue por una sola razón: intercambiar información, desde ese meme que te hizo reír, hasta las fotos de tus vacaciones o un mensaje importante. Cuando usas una Web, el DNS traduce el nombre a una IP para encontrarla; en una App, esta ya sabe a qué servidor llamar (vía API); y entre PCs, se hablan directamente de igual a igual. Para que este intercambio sea veloz y seguro, los datos se fragmentan en paquetes pequeños, viajan protegidos por capas de seguridad y, al llegar a su destino, se reensamblan para mostrarte el contenido completo en tiempo real.

Modelo Cliente/Servidor y Arquitectura

💻

Cliente (Frontend)

Representa lo que el usuario ve. Es la interfaz gráfica, los botones, colores y la experiencia directa. Es quien realiza la solicitud (Request) para obtener datos.

⚙️

Servidor (Backend)

Es lo que está por detrás. Se encarga de la lógica de negocio, el procesamiento de datos y la seguridad. Es quien envía la respuesta (Response).

Microservicios y el Rol Dual

Antiguamente las estructuras eran como un Monolito: un solo bloque gigante difícil de mantener. Hoy evolucionamos a los Microservicios: piezas independientes que se comunican entre sí.

  • API Gateway: Punto de entrada único que reparte el tráfico.
  • Bases de datos: Cada servicio tiene la suya propia (independencia total).

Protocolo HTTP en profundidad

Partes de éste protocolo (http) que facilitan la comunicación entre clientes y servidores en la web son:

Métodos HTTP (Anatomía de una Request / Response)

Son las acciones que el cliente solicita al servidor, como obtener información:

GET

Obtener

POST

Crear

PUT / PATCH

Actualizar

DELETE

Eliminar

Identificadores: URI, URL y URN

https:// www.ejemplo.com :443 /articulos ?categoria=tecnologia #introduccion
Haz clic en las partes de la URI para ver su función.

Cabeceras (Headers)

Contienen metadatos sobre la solicitud o respuesta. Los más usados:

Content-Type: JSON, HTML.
Authorization: Tokens.
User-Agent: Navegador.
Set-Cookie: Guardar datos.

Cuerpo del mensaje (Body)

Es el contenido enviado en las solicitudes o respuestas. Datos reales (JSON, HTML, imágenes).

Códigos de estado (Status Codes)

Indican el resultado de la solicitud:

✅ 2xx (Éxito)
🔀 3xx (Redirección)
❌ 4xx (Error Cliente)
🔥 5xx (Error Servidor)
