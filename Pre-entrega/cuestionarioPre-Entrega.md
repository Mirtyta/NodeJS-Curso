# Cuestionario autoevaluacion Pre-entrega

El cuestionario de Pre-entrega, son 9 preguntas, básicamente hay que contestar a todo si, pero se debe corresponder con lo que hicieron en su proyecto pre-entrega, les paso las preguntas para que sepan que es lo que deben tener presente en sus proyectos..  

RECUERDEN: El numero de pregunta puede no coincidir.  

Pregunta 1  
¿Hiciste uso de fetch para interactuar con la API de FakeStore?

Pregunta 2  
¿Aprovechaste métodos de arrays y strings para gestionar la entrada de datos?

Pregunta 3  
¿Configuraste el archivo package.json con "type": "module"?

Pregunta 4  
¿El programa permite listar todos los productos con npm run start GET products?

Pregunta 5  
¿Estructuraste tu código de manera clara y modular para facilitar la lectura y el mantenimiento?

Pregunta 6  
¿Utilizaste process.argv correctamente para capturar y procesar los comandos?

Pregunta 7  
¿Implementaste un script "start" en package.json para ejecutar el programa con npm run start?

Pregunta 8  
¿Implementaste destructuring y spread para manipular datos de manera eficiente?

Pregunta 9  
¿Has creado el directorio del proyecto e inicializado Node.js correctamente?
