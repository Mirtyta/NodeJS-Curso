Guía Pro: Node.js & GitHub

Configuración de cuenta, seguridad 2FA y despliegue de código.

1. Crear Cuenta en GitHub

  1. Visita github.com y haz clic en Sign Up.
  2. Sigue el asistente (correo, contraseña y nombre de usuario).
  3. Verificación: Confirma el código enviado a tu correo electrónico.

2. Seguridad: Validación en 2 Pasos (2FA)

GitHub requiere 2FA obligatoriamente. Recomendamos el método móvil por ser el más rápido:

Paso A: App Móvil

Descarga GitHub Mobile en tu celular (iOS/Android) e inicia sesión.

Paso B: Configuración

En la web: Settings > Password and authentication. Dale a Enable 2FA y elige "GitHub Mobile".

Nota: Guarda bien los "Recovery Codes" que te dará GitHub. Son tu único acceso si pierdes el celular.

3. Generar el Repositorio

Prepara el contenedor remoto:

  • Icono + → New repository.
  • Nombra tu proyecto (ej: node-service-api).
  • Selecciona Public o Private según el equipo.
  • Haz clic en Create repository y ten a mano la URL HTTPS.

4. Comandos de Consola

A. Inicializar Proyecto Local

# Crea el manifiesto de Node
npm init -y

# Crea el archivo principal
echo "console.log('Servidor activo');" > index.js

# EVITA SUBIR BASURA: Ignora la carpeta node_modules
echo "node_modules/" > .gitignore

B. Vincular y Desplegar

# Inicia el control de versiones
git init

# Agrega archivos al Stage
git add .

# Primer guardado oficial
git commit -m "Estructura base de Node"

# Rama principal
git branch -M main

# Conexión remota (PEGA TU URL AQUÍ)
git remote add origin https://github.com/usuario/repo.git

# Subida final
git push -u origin main
