## Pregunta ¿Cuál de las siguientes NO es una ventaja de usar Express Router?

a. Facilita la reutilización de conjuntos de rutas  
b. Mejora la organización del código  
c. Permite versionado de APIs  
**d. Aumenta la velocidad de procesamiento del servidor**  

Retroalimentación  
La respuesta correcta es: Aumenta la velocidad de procesamiento del servidor

## Pregunta La separación de responsabilidades en una arquitectura por capas es estrictamente necesaria para el funcionamiento de una aplicación

a. Verdadero  
**b. Falso**

Retroalimentación  
La respuesta correcta es: Falso  

## Pregunta Los controladores en una API REST se encargan de

a. Inicializar el servidor Express  
b. Definir la estructura de las tablas en la base de datos  
**c. Gestionar solicitudes HTTP, interactuar con la lógica de negocio y generar respuestas**  
d. Modularizar las rutas de la aplicación

Retroalimentación  
La respuesta correcta es: Gestionar solicitudes HTTP, interactuar con la lógica de negocio y generar respuestas

## Pregunta El prefijo '/api' en las rutas como app.use('/api', productsRouter) se utiliza principalmente para

a. Bloquear accesos no autorizados  
**b. Organización estética y para optimizar la búsqueda de rutas**  
c. Crear versiones diferentes de la misma API  
d. Ocultar las rutas reales a los usuarios

Retroalimentación
La respuesta correcta es: Organización estética y para optimizar la búsqueda de rutas

## Pregunta En una arquitectura basada en capas, el flujo de datos entre rutas, controladores y servicios es

a. Ruta → Servicio → Controlador  
**b. Ruta → Controlador → Servicio**  
c. Controlador → Ruta → Servicio  
d. Servicio → Controlador → Ruta

Retroalimentación  
La respuesta correcta es: Ruta → Controlador → Servicio

## Pregunta Al migrar lógica desde los controladores a los servicios, los controladores se limitan a

a. Manipular directamente la base de datos  
b. Manejar la autenticación y autorización  
**c. Recibir información de la solicitud, invocar servicios y responder al cliente**  
d. Definir la estructura de los datos  

Retroalimentación  
La respuesta correcta es: Recibir información de la solicitud, invocar servicios y responder al cliente  

## Pregunta Los servicios en una API REST encapsulan

**a. La lógica de negocio de la aplicación**  
b. La configuración del servidor  
c. Los métodos HTTP permitidos  
d. Los endpoints disponibles  

Retroalimentación  
La respuesta correcta es: La lógica de negocio de la aplicación  

## Pregunta La sentencia app.use('/api', productsRouter) en el archivo principal

c. Genera automáticamente rutas CRUD para productos

La respuesta correcta es: Integra el router de productos con el prefijo "/api"
